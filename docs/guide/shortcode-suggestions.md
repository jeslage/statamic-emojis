# Shortcode suggestions

Typing `:` and two characters (e.g. `:rock`) in Emoji Text or Bard lists matching emojis:
[custom ones](./custom-emojis) first, then by [Emojibase shortcode](https://emojibase.dev/docs/shortcodes),
name and keywords.

| Key           | Action           |
| ------------- | ---------------- |
| ↑ / ↓         | Choose           |
| Enter or Tab  | Insert           |
| Escape        | Close            |

Suggestions can be turned off on the [Emojis page](./settings).
